Offboarding a departing employee in Microsoft 365

The same-day checklist for when someone leaves.

Same-day checklist

When someone leaves, do this the same day, ideally while they're in their exit meeting:

  1. Block sign-in for the account in the Microsoft 365 admin center (Users, Active users, select the user, Block sign-in).
  2. Sign them out of all sessions and reset the password.
  3. Remove their MFA methods and any admin roles.
  4. Wipe company data from their phone if you use Intune.
  5. Collect laptops, security keys and building access.

Keep the mailbox and files

Don't delete the account right away. Convert the mailbox to a shared mailbox so a manager can read incoming mail (shared mailboxes under 50 GB don't need a license), and give their manager access to the person's OneDrive files. Microsoft deletes OneDrive content after a retention period once the account is deleted, so move what you need first.

Shared passwords and outside apps

Change any shared passwords the person knew, such as social media, banking portals and vendor sites, and remove them from outside apps that don't use Microsoft sign-in. A team password manager makes this much faster.
